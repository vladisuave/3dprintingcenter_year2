# 3D Printing Lab slides

Six weekly HTML slide decks (reveal.js) for the 3D Printing Lab, grades 3–5, converted from `3D Printing Center 26-27.key`.

- `index.html` – landing page linking to each week
- `week1.html` … `week6.html` – one deck per week; each includes the Lab Rules slide and speaker notes
- `assets/deck.css` – shared slide styling; `assets/reveal/` – vendored reveal.js 5.1.0 (MIT)

## Presenting
Arrow keys / space to navigate, **S** speaker view (notes), **O** overview, **F** fullscreen, **?** help.
Append `?print-pdf` to a deck URL and print from Chrome to export a PDF.

## Serving from GitHub
Push this folder to a repo, then Settings → Pages → deploy from the `main` branch root. No build step needed.
